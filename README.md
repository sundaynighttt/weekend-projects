# 선데이나잇의 주말 프로젝트

매주, 일하거나 생활하면서 ‘이런 게 하나 있으면 좋겠다’고 생각한 것 중 하나를 고릅니다. 주말에 혼자 기획하고, 화면을 디자인하고, 직접 쓸 수 있는 제품으로 만듭니다. 여기에 각 프로젝트를 시작한 이유와 완성한 모습을 모읍니다.

## 2026년 11월

[![자리기록의 일반 모드. 저장 사진과 촬영 시각을 한눈에 볼 수 있습니다.](https://raw.githubusercontent.com/sundaynighttt/desk-trace/main/docs/gallery.png)](https://github.com/sundaynighttt/desk-trace#readme)

### 자리기록 (DeskTrace) · macOS

회사에 켜 둔 맥북의 기록을 다음 날 아침 시간순으로 살펴보고 싶어 만들었습니다. 움직임이 있을 때는 카메라 사진을, 첫 입력이 들어올 때는 화면 한 장을 내 맥에 남깁니다.

[자리기록 사용해 보기](https://github.com/sundaynighttt/desk-trace/releases/latest) · [만든 이유와 사용법](https://github.com/sundaynighttt/desk-trace#readme)

## 2026년 10월

### H_TOOLZ · 웹

아침에 반복하는 일들을 한 화면에서 체크할 수 있도록 만든 루틴 도구입니다. 브라우저에서 일기, 아이디어, 영어 공부 같은 루틴을 한 줄씩 확인하고 진행 상황을 기록할 수 있습니다.

[브라우저에서 써보기](https://sundaynighttt.github.io/htoolz-site/app/)

## 2026년 9월

### Reset Signal · macOS · Windows

여러 공개 글을 계속 새로고침하는 대신, Codex 초기화에 관한 공개 참고 신호와 갱신 시각을 한눈에 보려고 만들었습니다. 앱과 위젯에서 발행된 신호를 확인할 수 있습니다.

[프로젝트 소개](https://github.com/sundaynighttt/tibo-reset-signal#readme) · [데스크톱 설치 파일](https://github.com/sundaynighttt/tibo-reset-signal/releases/tag/v0.1.0)

## 2026년 8월

### CodexTime · macOS · Windows

AI 서비스를 번갈아 쓰면서 도구마다 남은 사용량과 초기화 시간을 따로 확인하는 번거로움을 줄이고 싶었습니다. 연결한 서비스의 잔여량과 초기화까지 남은 시간을 한곳에서 보여줍니다.
