# 선데이나잇의 주말 프로젝트

매주, 일하거나 생활하면서 ‘이런 게 하나 있으면 좋겠다’고 생각한 것 중 하나를 고릅니다. 주말에 혼자 기획하고, 화면을 디자인하고, 직접 쓸 수 있는 제품으로 만듭니다. 여기에 각 프로젝트를 시작한 이유와 완성한 모습을 모읍니다.

### 자리기록 (DeskTrace) · macOS

회사에 켜 둔 맥북의 기록을 다음 날 아침 시간순으로 살펴보고 싶어 만들었습니다. 움직임이 있을 때는 카메라 사진을, 첫 입력이 들어올 때는 화면 한 장을 내 맥에 남깁니다.
